
Visualizing the data with matplotlib 

Plots

Bar plot
X = np.arange(10)
Y = np.random.uniform(0, 1, 100)
ax.bar(X, Y)

Box plot
Z = np.random.normal(0, 1, (100, 3))
ax.boxplot(Z)

Scatter plot
X = np.random.uniform(0, 1, 100)
Y = np.random.uniform(0, 1, 100)
ax.scatter(X, Y)

Pie chart
Z = np.random.uniform(0, 1, 4)
ax.pie(Z)


Histogram
Z = np.random.normal(0, 1, 100)
ax.hist(Z)

Can also bin with histogram, which means creating categories of multiple of something. For example, let’s say you have ages and voting trends for the last election but you want to group ages into youth, middle-aged, and senior categories. You can bin those ages. Be careful to pick good binning sizes.

plt.show()


Modifying plots 

Color
X = np.linspace(0, 10, 100)
Y = np.sin(X)
ax.plot(X, Y, color=”black”)

Line style (to dashed)
X = np.linspace(0, 10, 100)
Y = np.sin(X)
ax.plot(X, Y, linestyle=”--”)

Line thickness
X = np.linspace(0, 10, 100)
Y = np.sin(X)
ax.plot(X, Y, linewidth=5)

Adding ticks
X = np.linspace(0, 10, 100)
Y = np.sin(X)
ax.plot(X, Y, marker=”0”)

Label
ax.plot(X, Y)
ax.set_ylabel(None)
ax.set_xlabel(“Time”)


Range of colors (in a histogram)
X = np.random.randn(1000, 4)
cmap = plt.get_cmap(“Oranges”)
colors = cmap([0.2, 0.4, 0.6, 0.8])
ax.hist(X, 2, histtype=’bar’, color=colors)
